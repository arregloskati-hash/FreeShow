# FreeShow Church

FreeShow 1.6.5 with the church enhancements: Ember look, expanded draggable Groups arrangement (with "+" duplicate), group chips when importing songs and in Text edit, cleaner web-search lyrics, smoother lower thirds, Settings in the menu bar (⌘/Ctrl + ,), customizable shortcut keys (Settings → Shortcuts), readable ⚡ dynamic values, and a smarter stage "next group".

It starts blank on a new computer: no songs, projects or settings are included.

## Download

| Computer | File |
|---|---|
| Windows 10/11 | `FreeShow-Church-…-Windows-Setup.exe` |
| Mac with Apple Silicon (M1–M4) | `FreeShow-Church-…-Mac-Apple-Silicon.dmg` |
| Mac with Intel processor | `FreeShow-Church-…-Mac-Intel.dmg` |

(Not sure which Mac? Apple menu → About This Mac → "Chip": Apple M… = Apple Silicon, "Processor: Intel" = Intel.)

## Windows

1. Run `FreeShow-Church-…-Windows-Setup.exe`.
2. Windows may say "Windows protected your PC" (the installer isn't code-signed). Click **More info → Run anyway**.
3. Follow the installer. It installs to its own folder and adds a **FreeShow Church** shortcut.

## Mac

1. Open the `.dmg` and drag **FreeShow Church** onto **Applications**.
2. The first time, macOS blocks apps that aren't from the App Store or a registered developer. To allow it:
   - Open FreeShow Church once (it will be blocked), then go to **System Settings → Privacy & Security**, scroll down and click **Open Anyway**, or
   - in Terminal run: `xattr -dr com.apple.quarantine "/Applications/FreeShow Church.app"`
3. Open it again. macOS will ask for microphone/camera/screen access only when you use those features.

## Good to know

- FreeShow Church uses the same data folder as the official FreeShow. If the official FreeShow is already used on that computer, FreeShow Church will open its songs and settings. Don't run both at the same time.
- It doesn't update itself automatically; install a newer version from this page when there is one.
